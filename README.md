# 🔮 Sanctum Tarot Bot (@tarotxxbot)

Bot Telegram untuk pembacaan kartu Tarot dengan tema **Mistis & Misterius**, dilengkapi 78 kartu klasik Rider-Waite-Smith dan interpretasi bahasa Indonesia.

---

## ✨ Fitur Utama

1. **3-Card Spread (Tebaran Tiga Kartu):**
   - **Kartu I:** Masa Lalu (*Akar Energi & Pelajaran Batin*)
   - **Kartu II:** Masa Kini (*Realitas & Ujian Saat Ini*)
   - **Kartu III:** Masa Depan (*Arah Takdir & Konsekuensi*)
2. **Visual Kartu Normal & Bersih:**
   - Semua gambar kartu ditampilkan tegak lurus dan rapi.
   - Tanpa label posisi yang mengganggu.
3. **Pesan Gaib & Sintesis Benang Merah:**
   - Menyertakan elemen, kata kunci, tafsiran mendalam, dan bisikan gaib untuk setiap kartu.
   - Sintesis kosmik di akhir pembacaan.
4. **Bisikan Kartu Harian (Daily Meditation):**
   - Menarik 1 kartu untuk renungan hari ini.
5. **Mode Tombol Penuh (Button-Only):**
   - Menolak dan menghapus otomatis pesan ketik atau gambar dari luar agar ruang altar tetap bersih.

---

## 🚀 Perintah Bot (Telegram Commands)

- `/start` — Masuk ke Altar Sanctum dan menampilkan menu interaktif.
- `/tarot` atau `/baca` — Memulai ritual Tebaran Tiga Kartu.
- `/daily` — Menarik satu kartu panduan harian.

1. Buka PowerShell / Terminal di folder proyek:
   ```powershell
   cd C:\Users\Dipo\.gemini\antigravity\scratch\telegram-tarot-bot
   ```

   ```powershell
   .\.venv\Scripts\python.exe bot.py
   ```
3. Tekan `Ctrl + C` untuk menghentikan bot jika sudah selesai.
